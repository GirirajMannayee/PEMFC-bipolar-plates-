# Raw instrument data (to be deposited by the authors)

The manuscript tables only report mean +/- SD. The raw files below are **not contained in this repository yet** and have to be added
by the experimentalists before submission (the manuscript's Data-availability statement promises them). Each sub-folder has a
`TEMPLATE_*.csv` with the exact column layout expected by the scripts, and a README where needed.

| folder | content | consumed by |
|---|---|---|
| eis/ | impedance spectra, 4 temperatures x 3 replicates x 4 alloys | 02, 05 |
| polarisation/ | potentiodynamic curves (1 mV/s) | 03 |
| icr/ | ICR vs compaction pressure | 04 |
| hardness_conductivity/ | indents, four-point probe and eddy-current readings | (add own script) |
| xrd/ | diffractograms | (add own script) |
| sem_eds/ | micrographs and EDS maps (large images: use Git LFS or Zenodo) | - |
| ocp/ | OCP transients | - |
